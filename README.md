### Behind the screen

I'm the **CEO and Founder of Spreadle**. I build websites, apps,
developer tools, and automation—and usually end up involved in
everything from the first idea to the production logs.

I like knowing how things work, making useful things,
and having people around who enjoy doing the same.

AI is part of my workflow. So is reading the code it writes.

### Things I work on

I'll talk about the rest when it's ready. Probably.

### How I build

I don't have a favourite language or framework.
I use whatever fits the problem best.

Sometimes that's something I already know. Sometimes it means
learning something new. The goal is to build something that works
well and makes sense to maintain.
